# ♟️ Xadrez Online

Xadrez para dois jogadores em computadores diferentes, com salas por código.
Feito com Streamlit e python-chess.

1. Digite seu nome e clique em **Criar sala**.
2. Passe o código de 5 letras para o adversário.
3. Ele abre o mesmo link, vai em **Entrar numa sala** e digita o código.
4. Toque numa peça e depois na casa para onde quer ir.
